# TodoBoi

> A simple and efficient To-Do application built with **Laravel** as a hands-on project to explore its ecosystem from a **Ruby on Rails** developer's perspective.

---

## About The Project

**TodoBoi** is a straightforward task management web application created for learning and practice. Having a background in **Ruby on Rails**, this project served as a playground to compare framework paradigms, core concepts, and developer ergonomics between Rails and Laravel.

### Key Highlights & Learning Goals

* **Framework Transition:** Comparing Rails conventions (MVC, Active Record, Routes, Blade vs ERB) with Laravel's ecosystem (Eloquent, Artisan, Blade).
* **Core Functionality:** Task creation, updating, completion status, and deletion (CRUD).
* **Modern Stack Experience:** Exploring Artisan CLI, Laravel migrations, and request handling.

---

## Tech Stack

* **Backend:** PHP 8.5, Laravel 13
* **Database:** PostgreSQL
* **Frontend:** Laravel Blade, Tailwind CSS
* **Tooling:** Composer, NPM, Vite
